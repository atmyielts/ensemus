# Ensemus identity: Inner light

The wordmark is lowercase **ensemus** in Instrument Serif. The eye of the first e holds one point
of soft light: the intelligence inside the work, present but never shouting.

## Files

| File                                            | Use                                                       |
| ----------------------------------------------- | --------------------------------------------------------- |
| `ensemus-wordmark-ink.svg`                      | Primary logo on paper, white and other light backgrounds  |
| `ensemus-wordmark-bone.svg`                     | Logo on night and other dark backgrounds                  |
| `ensemus-mark-ink.svg`, `ensemus-mark-bone.svg` | The e alone, for tight spaces and avatars                 |
| `favicon.svg`, `favicon.ico` (16, 32, 48)       | Browser tabs                                              |
| `apple-touch-icon.png` (180)                    | iOS home screen; iOS rounds the corners itself            |
| `icon-192.png`, `icon-512.png`                  | Web app manifest                                          |
| `icon-maskable-512.png`                         | Android adaptive icon; the mark sits inside the safe zone |
| `icon-night-512.png`, `app-icon-night.svg`      | App icon on night                                         |
| `og-image.png` (1200 × 630)                     | Link previews                                             |
| `identity.png`                                  | This identity on one page                                 |

All letters are outlines, so no font needs to be installed to use these files.

## Colour

| Name       | Hex       | Role                                 |
| ---------- | --------- | ------------------------------------ |
| Paper      | `#F4F1EA` | Main light background                |
| Ink        | `#22261F` | Wordmark and text on light           |
| Sage       | `#7E8B72` | Quiet secondary text, rules          |
| Lime       | `#C2D45A` | The light, on light backgrounds only |
| Night      | `#12150F` | Main dark background                 |
| Bone       | `#EEEBE1` | Wordmark and text on dark            |
| Night lime | `#E2EE7C` | The light, on dark backgrounds only  |

The light is the only colour in the logo. Keep it small: it is a point, never a fill. Neon
Sun Glare (`#EDFF00`) is not part of the logo; if it is used at all, keep it to small accents on
night.

## Space and size

- Clear space: keep at least the height of the lowercase letters (the x-height) free on every side.
- Smallest wordmark: 72 px wide on screen, 18 mm in print. Below that, use the mark alone.
- Smallest mark: 16 px (favicon). The light stays visible at that size on paper.

## Please don't

- Recolour the letters, or colour any letter other than the light.
- Move, enlarge or animate the light out of the e's eye.
- Set the name in another typeface, stretch it, outline it or add effects (shadows, glows, gradients).
- Place the ink wordmark on busy photos; use a plain paper or night panel behind it.
