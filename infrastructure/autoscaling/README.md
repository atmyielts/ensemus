# Portable scaling plans

These YAML files are reviewable HPA-style/KEDA-style plans, **not directly applyable Kubernetes resources**. They deliberately have no cluster, image registry, namespace, selected metrics adapter, credentials, target or replica budget. A deployment integrator must translate the chosen plan into its platform's actual resources and refuse activation while any required value/binding is missing. Choose one controller per workload; never run competing controllers for the same replica count.

Web scales on authenticated request latency, platform activities on their own Temporal schedule-to-start signal, connector activities on their separate queue, and dispatcher on retained outbox age. Queue names match the runtime worker constants. Integrated M4 adds `agent-worker` (`node dist/agent-main.js`) on `ensemus-agent`, with a separate signal and configurable budget. It must remain on the isolated agents network, with its agent database role and private model/object/Temporal links. Do not move it to public or connector networks. Its runtime concurrency settings are not exposed yet; that binding is explicit root integration work, with no invented ceiling.

Connector concurrency must stay under an explicit low cap alongside provider quotas and uncertainty reconciliation. `tuningValue: 2` is a proposed test input only; the foundation connector worker currently has no corresponding configured cap, and these files do not enforce it. Bind reviewed `maxConcurrentActivityTaskExecutions` at the actual Worker composition root before activation. Increasing replicas multiplies total activity concurrency, database connections and gateway demand; enforce aggregate budgets as well as per-process caps. Autoscaling cannot resolve an unknown consequential effect or authorize a provider fallback.

Validate real metrics availability, configured limits, graceful shutdown, retained workflow behavior, tenant fairness, database pool pressure and scale-down recovery in an isolated reference environment. No scaling test or capacity result has been run by this source work.
