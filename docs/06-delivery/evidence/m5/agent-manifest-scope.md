- Studio's named `knowledge.<source UUID>.read` scopes now reach the actual worker compiler through the immutable run/version. No named Knowledge grant returns the base M4 context without calling a Knowledge model factory. `knowledge.read` has no approved broad meaning and is refused, as are malformed/case/whitespace variants of explicit scope syntax. A compile caller can narrow the retained manifest IDs, never widen them.
- Within one manifest the highest explicit `data.<class>.read` includes lower company-data classes, matching the domain simulator. Across the actual immutable parent/child lineage, explicit ceilings take the minimum and named Knowledge grants intersect. Missing data scopes preserve legacy M4 ABAC as the baseline; a missing Knowledge grant at any link grants no Knowledge access. Depth is bounded by the existing five-level contract; cycles, unknown ancestors or mismatched actual initiators refuse. Child execution is additionally unavailable until the real inherited-input receipt in 0416 exists; intersection alone is not input provenance.
- Company Work/file/source/fact material is capped separately from the model prompt's protection. Manifest objective/instructions are protected at least internally, including when company material is public. A public-company agent therefore needs an internally approved route for the prompt; a public-only model is not silently upgraded or used as a fallback. Internally labeled transcript/result material is permitted only after the retained actual company inputs independently pass the current and historical company-data checks.
- ContextSource, which also backs Work/file tools, checks the exact bound run/version and live actual metadata. 0414's restrictive agent Work SELECT predicate checks the current 0411 Work/project/client floor before the body can be returned. Object bytes are never read for a refused Work/file; fresh class/hash/ACL checks and durable observations still precede returned material. Transcript class headers are checked before private content selection, with a serialized retained-influence proof.
- Lexical/vector retrieval applies selected IDs and the current company-data ceiling in SQL before ranking/LIMIT and optional paid reranking/embedding. Verified facts require **all** evidence to fit the selected source set/current ceiling and subject floor before claim/subject bodies or capture are read. Unknown/missing evidence is not treated as an empty allowed list. Fresh access/class and exact read-at-time hashes remain independently required.
- Current influence admission retains old captured per-input classes after lowering/reparenting. It checks all actual prior observations, artifacts/ancestors, structured inputs, Knowledge package items and canonical call inputs, including dropped model candidates. It never uses overall run/package internal policy protection as evidence that company data was public and never invents or backfills a historical observation. Retained direct Knowledge package/call source IDs must still fit the immutable grant set.

## Rolling protocol and lock order

`app.agent_scope_protocol=scoped-v1:<actual run ID>` is a coherent bundled-runtime version claim, not authentication or a user-supplied authority. It is minted only by the actual immutable-scope/current-and-historical-influence admission helper after checks, never automatically by an agent database context. The original input-admission OID is preserved. Old bundles lack the marker and cannot read scoped Work, start/reclaim model steps, reuse scoped main reservations or publish scoped model results. Existing late accounting settlement/recovery remains possible after a permanent content fence.

Ordinary pre-body admission is metadata-only and does not hold a checkpoint/run lock while waiting for a new body/source row. Actual recording/dispatch/publication uses source/body locks first, sorted catalog NOWAIT checks, then checkpoint and run locks with inventory recheck. The first read may have an empty prior inventory only on a real complete/unfenced named run; provider dispatch requires actual retained Work/input evidence. Failed admission clears success scope. Receipt consumption saves/restores the new scope binding within the actual savepoint, including failure paths.

The generic tenant transaction and explicit webhook service context clear the scope key. The parent-requested four portability bindings are also cleared here, preserving existing native/model/job defaults. No app/private-response grant, secret, provider, spend default or duration was introduced.

## Explicitly blocked legacy delegation gate

The actual legacy delegation payload copies a model-produced **title** plus project/owner/class metadata into a new child Work; it does not copy an objective in this source. That title and child outputs can retain parent influences whose exact birth receipt is absent. New delegation refuses before copying any Work; a fixed SQL birth guard also rolls back a child run and copied Work atomically. Existing child admission is refused.

0414 records **actual existing** `(organization, child Work, child run, parent run)` identities in `ai.unproven_child_work_inputs`, while run writers are locked in the real migration transaction. This is an ID-only quarantine inventory, not a claim about inputs read or bytes purged. It has forced tenant RLS, app SELECT on organization/Work IDs only, no app/agent INSERT, no Work/run FK that could erase the evidence, and a fixed keep guard until 0416 has a real positive disposition. Temporary migrator metadata backfill policies are dropped immediately. The inventory remains visible after standing/metadata changes; deleting operational run rows cannot zero it.

The preserved 0411 `knowledge.work_scope_readable` predicate appends the inherited-input closure without changing its parent/catalog body; an additional restrictive Work SELECT closes **human and agent** body serving for actual unproven child Work. There is no generic service-viewer bypass. Existing Work/file/structured-lineage serving inherits the fence. A purge-job INSERT/UPDATE cannot claim `completed` while any unproven delegated sink remains in that tenant; an unknown source association cannot be guessed away. This blocks legacy-child source/byte/restore/erasure certification. M8 erasure must not delete this inventory first to obtain zero counts. Normal tenants with no inventory rows are unaffected by the row keep trigger.

0416 must add the actual exact-proposal/attempt delegation-birth dependency and lifecycle/serving/purge proof. No claim is made that delegation, legacy migration or restore is complete in this checkpoint.
