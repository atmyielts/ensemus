# Incident process and evidence

This is a runnable process; no drill is asserted complete. Severity follows `04-security/06-assurance-and-incidents.md`: critical includes confirmed cross-tenant disclosure, unauthorized restricted external transmission, compromised signing keys or unauthorized consequential actions; high includes suspected exfiltration, authorization bypass or business-critical unavailability; medium is bounded and mitigated impact. Confirm attribution separately: `ensemus`, `model_provider`, `connector_provider` or `unknown`.

The trusted operator binds `DATABASE_URL_OPERATOR`; the effective database role must be `ensemus_operator`. A supplied `operatorRef` or `authorRef` is attribution, never permission. Customer and support connections cannot operate this plane. Private reference files must be handled by the deployment's operator procedure. No operator web surface is provided.

1. Open: `node dist/ops.js incident open --file <private-json>` takes `operatorRef`, `severity`, `origin`, nullable `providerKind`, `publicTitle`, `commanderRef`, `isDrill`, and offset ISO `startedAt`. It starts private. A named commander is mandatory.
2. Assign: `incident roles --file <private-json>` takes `operatorRef`, `incidentId` and one or more `securityLeadRef`, `infrastructureLeadRef`, `communicationsRef`, `legalRef`. The actual people and handoff channel must be agreed by the operator, not inferred from the subject.
3. Update: `incident update --file <private-json>` takes `incidentId`, `state`, `publicMessage`, `authorRef`, `publish`, and optional `origin`. States before resolution are investigating, identified and monitoring. `publish: true` publishes the incident and its public update history. All update text must therefore be approved public text even while the incident remains private. Publication cannot be undone by sending false. Drills cannot be published. Origin corrections are explicit and audited.
4. Resolve: `incident resolve --file <private-json>` takes `incidentId`, `authorRef`, nullable `postmortemRef`, and public `message`. Critical/high incidents require the private postmortem reference. The update command cannot bypass that guard. Resolved incidents are terminal in this service; a recurrence gets a new incident and a private cross-reference in the evidence system.
5. Review: record timeline, cause, customer impact, missed detection, rollback/recovery evidence and assigned follow-ups in the restricted evidence channel. Publish only reviewed service-level updates. This service stores references to that evidence, not the private report body.

`/status` is dynamic, requires no session, reads only approved public columns under RLS and never includes commander, author or postmortem references. Failed reads report unknown. A model/connector provider incident says provider degradation; an unattributed incident stays unknown. It contains no measured uptime percentage.

## Gate F drill

The operator must choose a safe isolated environment, named commander, security lead, infrastructure lead, communications lead and legal contact. Create a private drill incident (`isDrill: true`), simulate one documented failure with generated data, diagnose through the corresponding runbook, restore service, test wrong-tenant denial and one-effect recovery, and verify public status never exposed the drill. Record exact start/end, release, environment and sanitized evidence in the restricted evidence system. If any part fails, record failed rather than passed.

`node dist/ops.js incident drill --file <private-json>` takes `operatorRef`, `kind` (`incident`, `restore`, `vulnerability_disclosure`, `failover`), `scenarioRef`, `roles` containing all five keys `commander`, `security_lead`, `infrastructure_lead`, `communications`, `legal`, offset ISO `startedAt`, nullable `finishedAt`, nullable `outcome` (`passed`/`failed`), and nullable `evidenceRef`. An unfinished record has all three completion fields null. A completed record needs all three, with finish at or after start. Records append; use a new evidence-linked record for a later result.
